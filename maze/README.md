# maze
C++を用いて作成した自動生成迷路ゲームです。
乱数を利用して壁を配置し、迷路を自動生成しています。生成後はBFS（幅優先探索）による経路探索を行い、スタートからゴールまで到達可能な迷路のみを採用しています。

![demo](maze/maze.gif)

## Demo
Windows版はReleaseからダウンロードして実行してください。

## Features
- 乱数を用いたランダムな壁配置による迷路生成
- BFS（幅優先探索）による経路探索で、スタートからゴールへの到達可能性を判定
- 難易度に応じた盤面サイズの変更機能
- プレイヤーの行動回数と最短経路長の表示
